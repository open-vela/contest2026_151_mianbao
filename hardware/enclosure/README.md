# DshanPixVela-Devkit 外壳（3D 打印）

决赛要求"不要裸板演示，可加装外壳"。这台板子的**官方资料里没有机械数据**
（原理图/IC 手册/照片，见 `5_硬件资料`；全网也没有 STP/结构图）—— 所以尺寸来自
**用户卡尺实测 + 背面照片标定**，用 `make_case.py` 参数化生成。

## 结构

"屏幕朝上三明治"：底板 + 铜柱(6mm) + 板(1.6mm) + 屏幕（板面到屏顶 14mm）。

| 件 | 内容 |
|---|---|
| `case_bottom.stl` | 底壳：四周侧壁开孔 + 底板 4×M3 安装孔（对准板上 4 个铜柱） |
| `case_top.stl` | 面框：顶部条带全开（排针/按键/喇叭露出）+ 屏幕开窗 + 裙边扣合 |
| 外廓 | 90.0 × 79.2 × 26 mm（面框再加 3mm） |

## 关键尺寸（来源标注）

> ⚠️ **2026-10-21 第二轮修正**：第一版试装"长宽都短一点、孔位偏" —— 根因是
> 当时间隙只给 0.6mm/边，且底边四个口的 X 是背面照片读数（±1mm）。本轮按
> **含凸起的总外廓**（88 × 75.5，旧 83.8×73 只是裸 PCB）+ 用户卡尺实测重定：
> 内腔 90 × 77.5（单边余量 1.0），外廓 **95 × 82.5 × 27.2**。

| 项 | 值 | 来源 |
|---|---|---|

| **总外廓（含凸起）** | 88 × 75.5 | 2026-10-21 实测（按钮/接口凸起） |
| 铜柱孔距 X × Y | 79 × 48.5，柱高 6（穿板，板下也露出） | 实测 |

## 重新生成

```bash
pip install trimesh manifold3d numpy
python make_case.py .          # 输出两个 STL + 三视图线框
```

改尺寸 → 只改脚本顶部的参数 → 重跑 → 重新上传。

## 待确认（第一版打印前最好量一下）

1. **铜柱 X 孔位**：已按实测 2.4mm（2026-10-17 用户实测 2.3~2.4 ✓）—— 无需再改。
2. **USB HOST 是单层还是双层** —— 已出**两个变体**，对着实物挑一个上传：
   | 文件 | USB 开窗 | 适用 |
   |---|---|---|
   | `case_bottom.stl` | 14 × 6.5 | **单层**（默认，用户实物确认） |
   | `case_bottom_usb_dual.stl` | 14 × 13.5 | 备用：上下两层叠口（宣传照长这样） |
   上传默认的 `case_bottom.stl` 即可（单层。2026-10-17 用户"插 U 盘"实测确认）。
3. 各接口**沿边位置**均来自照片（±1mm）：对不上就微调参数里的 X/Y 中心值。
4. 打印建议：PLA/PETG、层高 0.2、壁厚 ≥1.2mm（嘉立创 3D 打印默认即可）；
   屏幕开窗与板边留 2.5mm 卡边，若屏幕实际更窄可改 `bx + 2.5` 那两处。
