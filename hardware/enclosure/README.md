# DshanPixVela-Devkit 外壳（3D 打印）

决赛要求"不要裸板演示，可加装外壳"。这台板子的**官方资料里没有机械数据**
（原理图/IC 手册/照片，见 `5_硬件资料`；全网也没有 STP/结构图）—— 所以尺寸来自
**用户卡尺实测 + 背面照片标定**，用 `make_case.py` 参数化生成。

## 结构（2026-11-01 最后一次调整）

| 件 | 内容 |
|---|---|
| `case_bottom.stl` | **兜底件（默认打印）**：铜柱孔 ×1.5、底边四个口合成一条横槽、按钮侧整面去掉 |
| `case_bottom_precise.stl` | 精确件（对照用）：孔距/按键高度按实测修正，保留四个独立口与按钮侧壁 |
| ~~`case_top.stl`~~ | **顶盖暂不生成**（用户 2026-11-01 要求） |

外廓 **95.0 × 82.5 × 24.2 mm**（无面框；兜底件右侧敞开）。

## 2026-11-01 最后一轮调整

### 先修两条实测偏差（两个变体都生效）

1. **铜柱孔距 -1mm**：`STD_DX 80.5 → 79.5`、`STD_DY 49.0 → 48.0`
   （用户实测壳上孔距仍大约 1mm）。
2. **按键孔心高度 -1mm**：`Z_BOARD_TOP + 1.0 → Z_BOARD_TOP + 0.0`
   （用户反馈壳上位置高 1mm、往下调 1mm）。只影响**精确件**——兜底件把按钮侧
   整面去掉了。⚠️ 如果这句"垂直距离"你指的是**沿边方向**（K1/K2/K3 的 Y 间距），
   精确件还要再改 `KEY_YS_FROM_BOT`，告诉我即可；兜底件不受影响。

### 兜底方案（容错优先）

- **铜柱开口 ×1.5**：`STD_HOLE 4.2 → 6.3`（φ3 铜柱，单边余量约 1.65mm）。
- **底边四个口 → 一条横槽**（USB-C ×2 / TF / LCD&TP 全部合成）：
  - 水平：从最左口（USB-C1）左缘再往外 2mm，到最右口（LCD）右缘再往外 2mm
    → 绝对 X **14.0 ~ 81.5 mm**；
  - 垂直高度 ×1.5：4.5 → **6.75 mm**，仍以 USB-C 口心 `Z_USBC=8` 为中心
    → Z **4.625 ~ 11.375 mm**。
- **按钮侧（X=OUT_W 的右壁）整面去掉**：保留 3mm 底板边沿，按钮与 USB-A 直接
  露出。`case_bottom.stl` 不再挖 USB-A/按键孔——那一面已经没有壁了。
- **顶盖不生成**：`build_top()` 函数保留备用，`main()` 不再导出。

## 重新生成

```bash
pip install trimesh manifold3d numpy
python make_case.py .
```

输出：

- `case_bottom.stl` —— 兜底件（上传这个）
- `case_bottom_precise.stl` —— 精确件（对照/备用）
- 不再输出 `case_top.stl`

改尺寸 → 只改脚本顶部的参数 → 重跑 → 重新上传。

## 打印建议

PLA/PETG、层高 0.2、壁厚 ≥1.2mm（嘉立创 3D 打印默认即可）。兜底件的铜柱孔
φ6.3 对 φ3 铜柱余量较大，装配时可能需要垫片/少量热熔胶固定；这是为"最后一次
打印一定能装上"做的取舍。
